## 如何更新

1. 修改 `index.html` 中的介绍文字、链接或页面样式。
2. 更换头像时，上传新的 `avatar.png`，保持文件名不变。
3. 保存并提交修改（Commit changes），GitHub Pages 会自动更新网站。通常稍等几分钟，刷新网页即可看到。
